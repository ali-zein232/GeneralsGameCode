# Berserker Overlord Experiment

## Overview

Experimental modification for Command & Conquer: Generals Zero Hour that gives three Overlord variants enhanced combat capabilities when critically damaged.

### Supported units

- China Overlord (`ChinaTankOverlord`)
- Tank General Emperor (`Tank_ChinaTankEmperor`)
- Nuclear General Overlord (`Nuke_ChinaTankOverlord`)

## Features

- **Berserker activation:** At or below 35% health, while the unit is alive.
- **Damage bonus:** 1000% damage when Berserker is active.
- **Movement boost:** Increased speed, turning rate, and acceleration in the `REALLYDAMAGED` state.
- **Recovery:** The Berserker damage bonus is removed when health rises above 35%.
- **Death explosion:** Each supported Overlord fires `ChaosHumveeDeathWeapon` on death.

## C++ implementation

Changes are in:

- `GeneralsMD/Code/GameEngine/Include/GameLogic/Weapon.h`
- `GeneralsMD/Code/GameEngine/Include/GameLogic/Object.h`
- `GeneralsMD/Code/GameEngine/Source/GameLogic/Object/Object.cpp`

A new `BERSERKER` weapon bonus condition is registered. `Object::updateBerserkerState()` synchronizes the bonus with unit health after damage and healing.

## INI patches

Six patches are stored in the `ini/` directory:

- `GameData.patch`
- `Locomotor.patch`
- `Weapon.patch`
- `ChinaVehicle.patch`
- `TankGeneral.patch`
- `NukeGeneral.patch`

These patches were generated by comparing modified Zero Hour INI files against clean original versions.

### Applying the patches

From PowerShell, navigate to the root of a clean extracted Zero Hour `Data\INI` directory.

For example:

```powershell
$patchDir = "C:\Dev\GeneralsGameCode\experiments\berserker-overlord\ini"
$patches = Get-ChildItem $patchDir -Filter "*.patch" |
    Select-Object -ExpandProperty FullName

git apply --check -- $patches
git apply -- $patches
```

**Back up the target INI directory before applying patches.** Apply them only to a compatible, unmodified INI set. The patched INIs also require a compatible game executable built with the Berserker C++ changes.

## Testing

Successfully compiled and gameplay-tested all three Overlord variants, including critical-health activation, movement, damage, healing recovery, and death explosions.

## Experimental notes

This is a personal gameplay experiment, not a production-ready balance change.

Unrelated camera-height and Emperor Gattling turret modifications were deliberately excluded from the Berserker patch collection. These should be separated before preparing a focused community contribution.

The custom death weapon can also be shared with other experimental units.
