# Gameplay Experiments

This directory contains experimental modifications to Command & Conquer: Generals Zero Hour, primarily for learning C++, exploring game mechanics, and having fun.

Experiments are independent of the project's bug fixes and potential upstream contributions. Each preserved experiment has its own documentation and supporting files.

## Experiments

| Experiment | Description | Status |
|---|---|---|
| [Berserker Overlord](berserker-overlord/README.md) | Critical-health damage and movement bonuses, plus custom death explosions for three Overlord variants | Completed and tested |

Additional experiments will be documented here as they are preserved.
